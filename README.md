# **Sportova**

## 📌 Описание проекта
**Sportova** — это адаптивный веб-сайт, выполненный по макету в [Figma](https://www.figma.com/design/qeKXSaFTobjgOG9SPj6J26/Sport?node-id=0-1&p=f&t=Rz0bHkRkqUyvdD1Y-0). Сайт разработан с использованием **HTML**, **CSS** и **JavaScript**, чтобы обеспечить удобную навигацию и поддерживать адаптивный дизайн для различных устройств.

## 🎨 Функционал
- **Адаптивная верстка** для корректного отображения на устройствах с разными разрешениями экранов.
- **JS-скрипт** для управления мобильной навигацией (открытие/закрытие меню).
- **Кроссбраузерная поддержка**, обеспечивающая стабильную работу сайта в популярных браузерах.
- **Семантическая разметка**, соответствующая стандартам HTML5.

## 🛠 Используемые технологии
- **HTML5** — для структурирования контента.
- **CSS3** (с использованием Flexbox, Media Queries) — для стилизации и адаптивности.
- **JavaScript (Vanilla JS)** — для реализации функционала мобильной навигации.

## 🚀 Запуск проекта
1. Клонируйте репозиторий:
   ```sh
   git clone https://github.com/T-Atai-T/Sportova.git
   ```
2. Откройте файл `index.html` в вашем браузере.

## 📜 Навигация (JavaScript)
Для управления мобильной навигацией используется JavaScript-функция, которая позволяет скрывать и показывать меню на устройствах с небольшими экранами. В коде предусмотрена динамическая настройка высоты меню и смена иконки кнопки навигации при её открытии и закрытии.
